Section one

Number System

Understand it

The concept, explained properly

When you multiply a number repeatedly, only the unit digit of the previous result affects the unit digit of the next. Since there are only 10 possible unit digits, the pattern MUST eventually repeat — for 2, 3, 7, 8 it repeats every 4 powers. Once you know the cycle, you don't need the actual (huge) power, only where the exponent lands in the cycle.

The fast way

Trick

Find exponent mod (cycle length); use 4 instead of remainder 0; read off that cycle position. Also: HCF × LCM = product of the two numbers.

Confusion

Remainders must always be smaller than the divisor — negative or over-divisor remainders need adjusting back into range.

Fix

Warm up by writing the base's first 4 powers on scratch paper once, so the cycle is fresh in memory.

Worked examples

Worked example — Easy

Find the unit digit of 7&sup8;⁵.

Cycle of 7: 7,9,3,1 (length 4). 85 mod 4 = 1 → position 1 = 7.

Now you try — answers hidden

Find the unit digit of 3¹⁴⁴.
Cycle of 3: 3,9,7,1 (length 4). 144 mod 4 = 0 → use position 4 = 1.
HCF of two numbers is 12, LCM is 336. One number is 48. Find the other.
Product = HCF×LCM = 12×336 = 4032. Other number = 4032/48 = 84.
