Coding-Decoding

Understand it

The concept, explained properly

A coding rule is a fixed transformation applied to every letter the same way. Once you identify the rule from an example, applying it to a new word is pure mechanical substitution — the puzzle is in finding the rule, not applying it.

The fast way

Trick

Write out A=1...Z=26 on scratch paper first — turns letter-shifting into simple arithmetic.

Confusion

Some codes alternate direction per letter — verify the rule against the second letter too, not just the first.

Fix

Test your hypothesized rule against every given letter in the example before applying it to a new word.

Worked examples

Worked example — Easy

If CAT is coded as DBU, how is DOG coded?

Rule: each letter +1. D→E, O→P, G→H → EPH.

Now you try — answers hidden

If FLOWER is coded as EKNVDQ, how is GARDEN coded?
Rule: each letter −1. G→F, A→Z(wrap), R→Q, D→C, E→D, N→M → FZQCDM.
