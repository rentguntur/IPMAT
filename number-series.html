Number & Letter Series

Understand it

The concept, explained properly

Almost all series questions fall into a handful of underlying patterns: constant difference, constant ratio, a difference-of-differences, two interleaved sequences, or squares/cubes with an offset. Checking these in a fixed order turns pattern recognition into a systematic search instead of a lucky guess.

The fast way

Trick

Check in order: constant difference → constant ratio → difference-of-differences → interleaved series → squares/cubes ± constant.

Confusion

Two interleaved series (odd/even positions each following their own rule) often get mistaken for one broken pattern.

Fix

If the first three differences show no single obvious pattern, test the odd/even split hypothesis immediately.

Worked examples

Worked example — Easy

2, 3, 5, 8, 13, ___

Each term = sum of previous two. 8+13 = 21.

Now you try — answers hidden

Find the next term: 1, 4, 9, 16, 25, ___
Pattern: perfect squares (1²,2²,3²...). Next = 6² = 36.
Find the next term: 3, 6, 11, 18, 27, ___
Differences: 3,5,7,9 (increasing by 2 each time). Next difference = 11 → 27+11 = 38.
